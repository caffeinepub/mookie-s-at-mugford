# Specification

## Summary
**Goal:** Create a mobile-first, single-page marketing website for “Mookie’s at Mugford” with a cozy modern café aesthetic, accurate business details, clear sections, and polished CTAs.

**Planned changes:**
- Build a single scrollable landing page with sections in this order: Hero, About, Menu Highlights, Why People Love It, Reviews, Visit Us (with map), Footer.
- Implement CTA behaviors: smooth scroll to menu, “Order Online” modal/section with call-to-order fallback, and “Get Directions” opening a maps URL for 114 Washington St, Marblehead, MA 01945.
- Add Menu Highlights as image cards for the specified items plus a “View Full Menu” button that scrolls/expands in-page (no navigation away).
- Add Reviews section with the three provided quotes, a 5-star display, and total count “108 reviews” exactly as provided.
- Add Visit Us content: exact address/hours/service options, embedded interactive map, and clickable phone link tel:(781) 990-3282.
- Apply styling: warm neutral palette with espresso brown/cream/muted green accents, subtle animations, soft shadows, clean sans-serif typography, no clutter, no auto pop-ups.
- Implement basic local SEO: page title/description, Open Graph/Twitter meta tags, semantic headings (single H1), and LocalBusiness (or CafeOrCoffeeShop) JSON-LD with provided fields including rating/review count.
- Ensure performance/accessibility: optimized static images, lazy-load below-the-fold images, sufficient contrast, alt text for all images, keyboard/focus support (including modal focus trap/restore).

**User-visible outcome:** Visitors can scroll a visually polished single-page café site, view menu highlights with photos, read reviews and key details (exact business info), open directions in maps, and use CTAs to jump to sections or call to order.
